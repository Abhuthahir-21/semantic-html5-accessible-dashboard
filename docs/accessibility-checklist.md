# Accessibility checklist

- [ ] Every page has doctype, language, charset, viewport, and meaningful title.
- [ ] One clear page-level h1 and logical heading hierarchy.
- [ ] Semantic header, nav, main, aside, sections, articles, and footer used appropriately.
- [ ] Skip link is first in tab order and targets main content.
- [ ] All controls work with keyboard and show visible focus.
- [ ] Dialog opens, closes with Escape, and returns focus to trigger (verify in browser).
- [ ] Every form control has an associated label.
- [ ] Related controls use fieldset and legend.
- [ ] Tables have captions and scoped headers.
- [ ] Validate all pages at https://validator.w3.org/nu/ and save real results.
